**Empathia** is a mental health and emotional support chatbot designed to assist students. Built with cutting-edge technologies like **Google's Generative AI**, it provides supportive conversations to improve mental well-being. 🧠💬

---

## 🚀 Features

- 🤖 **AI-Powered Chatbot**: Offers emotional and mental health support.
- 🌐 **Web-Based Interface**: Built with **Flask** for accessibility.
- 🖥️ **Terminal Support**: Interactive command-line chatbot for power users.
- ⚙️ **Customizable Settings**: Adjust response parameters like temperature and tokens.

---

## 🛠️ Technologies Used

- **Google Generative AI**: For natural language processing and response generation.
- **Flask**: Lightweight Python framework for the web interface.
- **HTML/JavaScript**: To create an engaging chat interface.
- **dotenv**: To manage API keys securely.
